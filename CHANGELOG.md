## 0.0.21

### English
- **Window resize: the cards are computed once for each draw (measured by the user on 17.11.).** Before, `model.cards()` ran up to five times for each build, with a linear search per card. A draw now holds `StoreModel::frame_cards()`; inside it the cards are computed once and shared (`cards_shared()`), outside a draw nothing is cached, so nothing can go stale. `EngineBackend::icon_path` no longer calls `is_file()` for each card for each build: the icon folder is read once per listing. Measurement of the user (frame log, same build with and without the cache, resize frames): median **881 ms without, 109 ms with** the cache (p95 968 / 141 ms). **The goal of 16 ms per frame is NOT reached**: 104 ms of the 109 are still our build, tree, style and layout (`rebuild_ms`); the next steps (tooltips and drop-downs only on hover, a virtual list, fewer elements per tile) follow. The index below was not part of the measured build.
- **Cards through an index by name:** the card list reads the rows through a map by name (one lookup per card instead of a scan of every list per card, was O(N^2)); the first row of a name wins, as the scan did. Not measured on its own.
- **Measuring hook:** `fs-components` is pinned to v0.0.26; `FS_FRAME_LOG=<file> fs-packages` writes one CSV row per frame (`t_ms,kind,total_ms,check_ms,rebuild_ms,tick_ms,render_ms,chain_ms,width,height`). How to measure: `docs/measuring.md` (en/de). Nothing happens without the variable.
- **The log of a started program is limited to 64 KB at all times** (finishes the promise of 0.0.20): the program writes into a pipe, and a small process of its own (`fs-packages log-pump <log>`, internal) keeps the last 64 KB in the file. The pump outlives the store and the process that was started and ends with the last writer of the pipe, so the limit also holds after the start process has ended and after the store is closed. The other ways were refused on evidence: a file size limit of the process (`RLIMIT_FSIZE`) would also limit every other file the program writes (its data) and ends the program with a signal when it is reached; a reader thread inside the store ends with the store, and the program would then die of a broken pipe. A write error of the log never stops the reading. If the pump cannot be started the tile says so and the program starts without a log.
- **The log is never made through a symbolic link:** the file is opened with `O_NOFOLLOW`, the log folder is checked with `symlink_metadata` (no link) before its rights are touched; a link makes the log unwritable (told on the tile with the cause), the file or folder it points to stays as it was, and the program starts anyway. Tests with a link to a foreign file and to a foreign folder.
- **A start that hangs is told:** a program that still runs 8 seconds after the start and shows no sign of life (no display or graphics library loaded in it or its children, read from `/proc` of the store's own child on Linux; nothing is read of any other process or session) gets a hint on its tile, in the package page and in the compact variant: "running for N s, no sign of life (no window); not responding: stop it?" with "Open log" and "Stop it". "Stop it" ends only the process the store started, by its handle (never by name, never another process). The hint goes when the program shows a sign. Where nothing can be read (not Linux), nothing is told: unknown is not "hangs". A program linked to those libraries from its first moment counts as alive, so the hint can be missing, never wrong in that direction.

- **Bekannte Grenzen:** Die rpm-Seite ist mit einem Ordner statt `/usr/bin` getestet, nicht mit echtem `dnf`; `relink` vertraut `installed.toml`; ein Link, der direkt in `packages/` zeigt (nicht über `current/`), wird nicht geprüft. Die Form wird nur über `packages/<name>/<version>` entschieden: Liegen tar.gz und rpm mit GLEICHER Version vor, gewinnt die entpackte Form. Ein Versionsordner unter `packages/<name>/` ohne passende Dateiliste wird ganz entfernt, ohne Prüfung auf Fremddateien (nur ein Ordner mit Liste wird geprüft).
